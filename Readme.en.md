## Introduction
[中文版本](Readme.md)

"Heart Umbrella - Healing Assistant" is a browser extension designed to gently block words you don't want to see and heal your mind with encouraging and comforting words. It is dedicated to providing you with a more positive and comfortable online browsing experience.

## Features
- **Smart Word Blocking**: Automatically blocks unwanted words on web pages according to your settings.
- **Mind Healing**: While blocking words, it provides encouraging and comforting messages to help you maintain a positive mindset.

## Installation

### Install from Firefox Add-ons
https://addons.mozilla.org/addon/%E5%BF%83%E4%BC%9E-%E6%B2%BB%E6%84%88%E5%B0%8F%E5%8A%A9%E6%89%8B/

### Manual Installation
1. Download and unzip the project code.
2. Open the Firefox browser, type `about:debugging#/runtime/this-firefox` in the address bar, and press Enter.
3. Click "Load Temporary Add-on..." and select any file inside your unzipped project folder.

## Usage
1. After installation, the extension icon will appear in your browser toolbar.
2. Click the icon to open the extension interface, where you can view the current status or perform quick operations.
3. Click the "Options" button in the pop-up interface (or directly visit `about:addons`, find this extension, and click "Details" -> "Options") to enter the settings page, where you can:
    - Add or remove blocked words.
    - Customize healing messages.
    - Adjust other related settings.
4. The extension will automatically take effect when you browse web pages, blocking words and providing healing according to your settings.
