## 介绍 (Introduction)
[English Version](Readme.en.md)

"心伞 - 治愈小助手" 是一款浏览器扩展，旨在温柔地屏蔽您不想看到的词汇，并用鼓励和安慰的话语治愈您的心灵。它致力于为您提供一个更积极、更舒适的在线浏览体验。

## 特性 (Features)
- **智能词汇屏蔽**: 根据您的设置，自动屏蔽网页上不希望看到的词汇。
- **心灵治愈**: 在屏蔽词汇的同时，提供鼓励和安慰的信息，帮助您保持积极心态。
- **直观的弹出界面**: 快速访问扩展功能和状态。
- **个性化设置**: 通过选项页面，您可以自定义屏蔽词汇列表和治愈信息。

## 安装 (Installation)

### 从 Firefox Add-ons 安装 (Install from Firefox Add-ons)

直接在Firefox Add-ons中搜索"心伞 - 治愈小助手"

### 手动安装 (Manual Installation)
1. 下载并解压本项目的代码。
2. 打开 Firefox 浏览器，在地址栏输入 `about:debugging#/runtime/this-firefox` 并回车。
3. 点击“加载临时附加组件...”，然后选择您解压后的项目文件夹中的任意文件。

## 使用 (Usage)
1. 安装完成后，扩展程序图标将出现在您的浏览器工具栏中。
2. 点击图标，将弹出扩展程序界面，您可以在此查看当前状态或进行快速操作。
3. 点击弹出界面中的“选项”按钮（或直接访问 `about:addons` 找到本扩展并点击“详情”->“选项”），进入设置页面，您可以：
    - 添加或删除屏蔽词汇。
    - 自定义治愈信息。
    - 调整其他相关设置。
4. 扩展程序将在您浏览网页时自动生效，根据您的设置屏蔽词汇并提供治愈。
